# Tugas 2: Fungsi Elemen dan Atribut HTML

| No. | Elemen/atribut | Fungsi |
| :--- | :--- | :--- |
| 1 | `<!DOCTYPE>` | Memberi tahu browser tentang versi HTML yang digunakan di halaman web (deklarasi tipe dokumen). |
| 2 | `<html>` | Menentukan root halaman HTML dan memberi tahu browser bahwa dokumen tersebut adalah dokumen HTML. |
| 3 | `<head>` | Memuat metadata yang isinya tidak ditampilkan di browser pada saat halaman dimuat. |
| 4 | `<title>` | Menampilkan judul halaman web di bagian atas jendela browser. |
| 5 | `<body>` | Menentukan konten utama dari dokumen HTML yang muncul di browser. |
| 6 | `<h1>` - `<h6>` | Menentukan ukuran teks untuk judul/heading, mulai dari ukuran terbesar (h1) hingga terkecil (h6). |
| 7 | `<b>` | Membuat format teks tebal. |
| 8 | `<i>` | Membuat format teks *italic* (miring). |
| 9 | `<mark>` | Membuat format teks dengan *highlight* atau sorotan. |
| 10 | `<small>` | Membuat format teks berukuran kecil. |
| 11 | `<sub>` | Membuat format teks *subscript* (posisi teks agak ke bawah). |
| 12 | `<sup>` | Membuat format teks *superscript* (posisi teks agak ke atas). |
| 13 | `<del>` | Membuat format teks yang dicoret. |
| 14 | `<ins>` | Membuat format teks *underline* (bergaris bawah). |
| 15 | `<img>` | Bertugas untuk menyisipkan sebuah gambar ke dalam halaman web. |
| 16 | `src="gambar.jpg"` | Menambahkan informasi URL atau lokasi gambar yang akan ditampilkan pada elemen img. |
| 17 | `alt="gambar1"` | Memberikan teks alternatif pada gambar. |
| 18 | `height="200"` | Mengatur tinggi gambar sebesar 200 piksel. |
| 19 | `width="200"` | Mengatur lebar gambar sebesar 200 piksel. |
| 20 | `<ul>` | Membuat daftar tak berurut (*Unordered List*) dengan simbol seperti lingkaran atau kotak. |
| 21 | `<ol>` | Membuat daftar berurut (*Ordered List*) dengan angka atau huruf. |
| 22 | `type="circle"` | Menentukan tipe *unordered list* agar menggunakan simbol lingkaran kosong (*circle*). |
| 23 | `<dl>` | Membuat daftar deskripsi (*Description List*). |
| 24 | `<dd>` | Mendefinisikan isi atau deskripsi dari suatu istilah dalam *Description List*. |
| 25 | `<br>` | Membuat baris baru atau *line break*. |
